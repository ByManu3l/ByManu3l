### Proyectos

- **[GritBase](https://gritbase.app)**: gestión de clientes, cobros y asistencia para gimnasios. Funciona en web, Windows y Android, y sigue operando sin internet. Lo desarrollo y opero solo; el código es privado.

- **[STOCKERR](https://github.com/BauPP/stockerr1)**: sistema de inventario por microservicios con Node.js, PostgreSQL y Docker, hecho en equipo.
