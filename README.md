### GritBase · [gritbase.app](https://gritbase.app)

Software de gestión para gimnasios en Colombia: clientes, cobros, asistencia, rutinas y reportes. Es mi producto: lo diseño, desarrollo y opero solo, y lo usan gimnasios que pagan una suscripción.

- Funciona sin internet y se sincroniza al volver la conexión.
- Web instalable, programa de Windows con actualizaciones automáticas y app de Android.
- Los datos de cada gimnasio están aislados desde la base de datos.
- Pagos en línea, pruebas automatizadas y despliegue continuo.

Next.js · TypeScript · PostgreSQL · Supabase · Tauri · Cloudflare. El código es privado.
