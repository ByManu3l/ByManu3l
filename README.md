## GritBase — plataforma operativa para gimnasios

SaaS en producción para la gestión integral de gimnasios: web (PWA), escritorio y móvil, con sincronización offline-first. Proyecto personal que llevo de extremo a extremo como único desarrollador: 350+ commits en ~3 meses, del esquema de datos al despliegue.

![Next.js](https://img.shields.io/badge/Next.js-000000?style=flat-square&logo=nextdotjs&logoColor=white) ![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white) ![Supabase](https://img.shields.io/badge/Supabase-3FCF8E?style=flat-square&logo=supabase&logoColor=white) ![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white) ![Tauri](https://img.shields.io/badge/Tauri-24C8DB?style=flat-square&logo=tauri&logoColor=white) ![Vercel](https://img.shields.io/badge/Vercel-000000?style=flat-square&logo=vercel&logoColor=white)

**Arquitectura** · monorepo Turborepo · PWA en Next.js (App Router) · escritorio con Tauri · móvil con Capacitor · sincronización offline-first con PowerSync

**Funciones** · pagos en línea (Wompi/Stripe) · check-in por QR · generación de PDF · notificaciones web-push · i18n es/en

**Ingeniería** · CI/CD · pruebas e2e (Playwright) y unitarias (Vitest) · 45 migraciones de base de datos · políticas RLS
