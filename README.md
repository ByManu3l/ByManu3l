## GritBase — plataforma operativa para gimnasios

SaaS en producción para la gestión integral de gimnasios: web (PWA), escritorio y móvil, con sincronización offline-first. Proyecto personal que llevo de extremo a extremo como único desarrollador: 350+ commits en ~3 meses, del esquema de datos al despliegue.

**Stack** · Next.js (App Router) · TypeScript · Supabase (PostgreSQL, Auth, RLS) · PowerSync · Tauri · Turborepo · Vercel

**Funciones** · pagos en línea (Wompi/Stripe) · check-in por QR · generación de PDF · notificaciones web-push · i18n es/en

**Ingeniería** · CI/CD · pruebas e2e (Playwright) y unitarias (Vitest) · 45 migraciones de base de datos
